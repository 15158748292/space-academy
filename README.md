# 星际学园 · 玩中学太空工作台

> 为五年级小学生量身定制的太空主题学习工作台，涵盖英语、作文、数学三科。

## 项目简介

这是一个网页应用，孩子创建宇航员角色后，可以在三个"星球"上完成任务获得积分、提升等级、解锁勋章。整个过程包装成太空冒险任务，让孩子在"玩"中学习。

## 主要特性

- **太空主题视觉**：深蓝紫星空背景 + 闪烁Canvas星空 + 三大彩色星球
- **三科内容**：
  - 英语星球：单词星际航行、句子修复站、听力雷达站、对话外星人
  - 数学星球：燃料计算器、星际航线、密码方程式、基地建造师
  - 作文星球：故事引擎、词语星桥、场景全息台
- **积分勋章系统**：10级等级体系 + 12个太空主题勋章
- **Web Speech API**：英语听力自动发音，作文可朗读
- **响应式设计**：平板/桌面/手机均可使用
- **进度自动保存**：localStorage本地存档

## 使用方法

### 启动本地服务器

由于使用了 Web Speech API 等浏览器特性，需通过 HTTP 服务器访问（不能直接双击HTML打开）。

```bash
cd space-academy
python3 -m http.server 8080
```

然后在浏览器中打开 `http://localhost:8080`

### 孩子使用流程

1. **启航舱**：输入名字（最多8个字）+ 选择宇航员头像
2. **星际母舰首页**：看到三个星球入口（英语/数学/作文）
3. **进入任一星球**：选择具体任务类型开始答题
4. **完成任务**：获得积分 → 自动判定升级 → 弹升级动画
5. **勋章墙**：查看已获得的太空主题勋章
6. **宇航员档案**：查看个人进度、各科目完成情况

### 家长引导建议

- 第一次使用时，陪孩子完成"启航舱"的角色创建
- 鼓励孩子先从英语词汇和数学燃料题入手，建立信心
- 看到孩子答错时不用干预，应用的鼓励语会引导
- 每周查看一次"宇航员档案"，了解孩子的进度
- 建议每次学习 15-20 分钟，自由探索不同星球

## 设计理念

- **玩中学不是口号**：每道题都是太空任务，不是"做题"而是"执行任务"
- **保护脆弱的信心**：答错不批评只引导，难度自适应，从最简单开始
- **让进步看得见**：积分、等级、勋章多重可视化成就感

## 浏览器兼容性

- ✅ Chrome / Edge（推荐）
- ✅ Safari
- ✅ Firefox
- ✅ 平板浏览器（iPad / 安卓平板）
- ⚠️ Web Speech API 需 HTTPS 或 localhost 才能正常发音

## 题库扩展

题库在 `js/data/` 目录下，按以下格式添加新题目：

- `english-questions.js`：英语4种题型
- `math-questions.js`：数学4种题型
- `writing-frames.js`：作文3种模式

每个题目都是普通JS对象，按结构添加即可。

## 技术栈

- 纯HTML/CSS/JavaScript（无框架依赖）
- Web Speech API（语音合成）
- Canvas API（星空背景）
- localStorage（进度存档）
- CSS Animations（动画效果）
